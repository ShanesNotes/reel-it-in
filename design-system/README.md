# Design System

This folder contains the extracted Reel It In design system.

## Contents

- `colors_and_type.css`: color, typography, spacing, motion, and theme tokens
- `accessibility.md`: contrast notes and accessibility constraints
- `assets/`: reusable brand texture and wordmark specimens
- `fonts/`: font-loading notes
- `preview/`: small visual specimens (`preview/index.html` links them all)
- `screenshots/`: reference screenshots from prior design passes
- `ui-kits/`: higher-fidelity HTML/CSS/JSX prototypes

## Brand Summary

Reel It In should feel like a warm printed magazine and a calm production surface, not a glossy AI startup page.

Use:

- cream paper
- warm near-black ink
- restrained gold accent
- teal as a secondary signal
- Fraunces display type
- Hanken Grotesk body/UI
- JetBrains Mono labels
- subtle film grain

## Working Rule

The design system supports the product. If a component or specimen does not help the dashboard, show workflow, or production assets, it should stay clearly marked as reference material.
