# Episodes

This folder holds per-episode working material.

Each episode should eventually have:

- prep notes
- source links
- recording notes
- edit notes
- final title and description
- thumbnail ideas
- final archive metadata

## Naming

Use numbered folders:

```text
001-pilot/
002/
003/
```

Use the starter automation to create a new folder:

```powershell
.\tools\new-episode.ps1 -Title "Episode working title"
```

The script uses `episodes/_template/` and creates:

- `episode.md`
- `sources.md`
- `research-inbox.md`
- `research-inbox.json`
- `research-drafts.md`
- `research-drafts.json`
- `research-scout.md`
- `research-candidates.json`
- `dad-brief.md`
- `production-notes.md`
- `publishing.md`
- `title-thumbnail.md`
- `title-thumbnail.json`
- `thumbnail-images.json`
- `transcript.md`
- `edit-plan.md`
- `edit-plan.json`
- `archive.json`
- `automation-report.md`
- `handoff/session-launch.md`
- `handoff/edit-plan.md`
- `handoff/editor/`
- `handoff/dad-packet.md`
- `handoff/recording-packet.md`
- `handoff/editor-packet.md`
- `handoff/publishing-packet.md`
- `handoff/marketing/`

`research-inbox.md` and `research-inbox.json` are generated from the feed watchlist at `docs/RESEARCH_WATCHLIST.json`. Copy promising rows into `sources.md`, then add the real "why it matters."

`research-drafts.md` and `research-drafts.json` are generated from the feed inbox. They score items and draft candidate rows, but Shane still chooses what enters `sources.md`.

`research-scout.md` and `research-candidates.json` are generated from `sources.md`. Use them to see the slate shape, missing research, and the prompt for the next Codex research pass.

`page-summaries.md` and `page-summaries.json` are optional outputs from `tools/fetch-page-summaries.py` when inbox summaries are empty.

`x-insights.md` and `x-insights.json` are optional outputs from `tools/collect-x-insights.py` (Grok Build). `tools/export-dashboard-data.ps1` can merge `xInsight` into dashboard news beats.

`handoff/` is generated from the episode files and contains the shareable Dad, recording, editor, and publishing packets. `session-launch.md` is generated by the recording-session launcher and records the local media folders and open targets for that recording day.

Solo Reaction Episodes also use:

- `source-ingest.md`: human-readable ingest summary and external transcript pointer
- `youtube-ingest.json`: machine-readable ingest metadata from `tools/prepare-reaction-episode.py`

`edit-plan.md`, `edit-plan.json`, `handoff/edit-plan.md`, and `handoff/editor/` are generated from `production-notes.md` and `transcript.md`. Use them for the Descript pass, chapter CSVs, clip candidates, and transcript cleanup checks.

`handoff/marketing/` is generated from `publishing.md` and contains platform-specific upload files, social/newsletter copy, clip CSVs, distribution checklists, and structured upload fields.

`title-thumbnail.md`, `title-thumbnail.json`, and the title/thumbnail files under `handoff/marketing/` are generated from the selected episode stories. Use them to pick upload titles, brief thumbnails, and create image-generation prompts. `thumbnail-images.json` and `handoff/marketing/generated-thumbnails.md` are written when image generation is attempted or intentionally skipped.

`dad-brief.md` is generated from `episode.md` once the story slate is selected. Keep recording date, time, and link there so the Dad packet and recording launcher can reuse them.

`episodes/index.json` is generated from per-episode `archive.json` files and is the machine-readable shelf.
