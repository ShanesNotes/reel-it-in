# Project Brief

## One-Line Description

Reel It In is a father-son conversation show that makes fast-moving AI news understandable, human, and worth caring about.

## Core Format

Shane follows AI closely. Dad keeps him grounded. The show works because Dad can stop the technical drift and ask the audience's real question: "why does that matter?"

The show should feel like a smart kitchen-table conversation with strong production taste, not a tech analyst broadcast.

## Audience

Curious everyday people who hear about AI constantly but do not follow every model release, policy fight, or product launch.

The audience is not "senior citizens" literally. Dad is a useful proxy: intelligent, curious, not immersed in the jargon.

## Product In This Repo

The first product is a host/operator dashboard:

- prep surface for one episode
- weekly template
- live recording substrate
- episode packaging and publishing helpers (`tools/`, `production/publishing/`)

The current dashboard is `app/reel-it-in.html`.

## Brand Direction

Warm, tactile, editorial, analog. The counter-positioning matters: most AI media looks cold, blue, glossy, and futuristic. Reel It In should feel like a printed independent magazine that happens to be about AI.

## Creative Tension

AI is technical and fast. The show is human and slow enough to understand. The dashboard should help Shane move from "what happened" to "why it matters" without over-scripting the conversation.

## Current Assets

- self-contained pilot HTML dashboard
- extracted design system with color/type tokens, previews, screenshots, UI kit prototypes
- intro montage handoff concept, prompts, and visual board
- show workflow and roadmap docs

## Near-Term Outcome

Get to a repeatable first recording:

1. pick real episode topics
2. prepare sources and sparks
3. record with the dashboard
4. capture edit notes
5. publish a clean episode package
