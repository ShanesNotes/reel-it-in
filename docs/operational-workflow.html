The Weekly Loop

run from the repo root · Linux/macOS: prefix with pwsh -NoProfile -File
0

Check State

See what changed, confirm the latest episode, and avoid working from stale assumptions.

git status --short .\tools\episode-status.ps1
1

Open The Episode

Create the folder that will hold prep, research, dashboard data, edit notes, marketing, and archive metadata.

.\tools\new-episode.ps1 -Title "Working title"
2

Research And Scout

Collect official feeds, draft candidate rows, validate links, and make the slate visible.

.\tools\collect-research-feeds.ps1 -Episode <episode> .\tools\draft-research-candidates.ps1 -Episode <episode> .\tools\generate-research-scout.ps1 -Episode <episode> .\tools\validate-sources.ps1 -Path .\episodes\<episode>
3

Select And Prep

Shane chooses the angle, stories, and sparks. Codex turns that into Dad prep and dashboard data.

.\tools\generate-dad-brief.ps1 -Episode <episode> .\tools\export-dashboard-data.ps1 -Episode <episode> -UpdateDashboard
4

Record

Launch the dashboard, notes, handoff packet, recording room, and media folders.

.\tools\start-recording-session.ps1 -Episode <episode>
5

Wrap And Edit

Turn live notes and transcript markers into an editor-ready plan, clips, chapters, titles, and thumbnail concepts.

.\tools\generate-edit-plan.ps1 -Episode <episode> .\tools\generate-title-thumbnail-package.ps1 -Episode <episode> .\tools\generate-publishing-package.ps1 -Episode <episode> -Force .\tools\export-production-packets.ps1 -Episode <episode>
6

Package And Publish

Split the finished publishing package into upload fields, platform copy, social posts, clip CSVs, and title/thumbnail handoff files.

.\tools\export-marketing-assets.ps1 -Episode <episode>
7

Archive

Save final metadata, refresh the episode shelf, and run the readiness report.

.\tools\export-archive-metadata.ps1 -Episode <episode> -UpdateIndex .\tools\run-episode-pipeline.ps1 -Episode <episode>

Solo Reaction Lane

one source video, same one-folder rule
A

Ingest And Prep

Create or refresh a Solo Reaction Episode from a YouTube URL. Transcript artifacts stay under ~/university/; this repo keeps pointers only.

python3 tools/prepare-reaction-episode.py --url <youtube-url> --ingest --force
B

Record And Package

Stream or record with commentary notes, then run the normal packaging tools when ready.

pwsh -NoProfile -File ./tools/run-episode-pipeline.ps1 -Episode <episode> -SkipSourceValidation -SkipResearchFeeds

Service Stack

what runs where
GitHub Shared source of truth for docs, scripts, episode metadata, and handoff files.
Cloud Media Raw tracks, exports, clips, thumbnails, transcripts, and masters outside git.
Riverside Primary recording room with separate high-quality tracks.
OBS Optional safety capture, dashboard capture, or video layout.
Descript Transcript-first edit, speaker labels, captions, and clips.
Auphonic Final loudness, leveling, and repeatable audio polish.
