## Goal

Use Storyboard Studio as previs for the Golden Thread intro montage.

## Outcome

Storyboard Studio did not preserve the composed board after pressing Done, but the generated image assets remained in the Flow project media grid.

This is acceptable. The board was useful as a generator and direction-finding tool, but final production should treat generated images as selects/assets rather than relying on Storyboard Studio state.

## Practical Lesson

Before pressing Done in Storyboard Studio:

1. Screenshot the board.
2. Favorite or pin the strongest frames.
3. Download the most important selects if Flow allows it.
4. Rename assets if Flow supports naming.

Do not assume the composed storyboard layout will be preserved.
