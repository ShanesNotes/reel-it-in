# Intro Prototypes

Local, controllable intro animation experiments for Reel It In.

## Golden Thread Cut

- File: `golden-thread-intro.html`
- Length: 10.8 seconds
- Format: 16:9 canvas animation with HTML wordmark overlay
- Purpose: a owned fallback to the Flow experiments, suitable for OBS/browser screen capture and timing iteration

This cut keeps the design-system title resolve but adds the Golden Thread story procedurally:

1. spark over black water
2. thread unspools into proto-circuit geometry
3. ziggurat/ascent impression
4. floodwater and surviving thread
5. deep-water shadow and catch
6. horizontal gold waterline into the Reel It In wordmark

Open the HTML file directly in a browser. Use the controls to scrub timing before capture.

For a clean full-window capture without controls, add `?capture=1` to the URL.
For a paused frame, add `?t=9.8&play=0`.
