# Intro Montage

Working concept: **The Golden Thread**.

The direction is ancient-futuristic: illuminated manuscript meets archaic machine. Gold leaf, circuitry, clay, code, bronze, light, and a single luminous thread.

## Files

- `prompts.txt`: video and music generation prompts
- `FLOW_OMNI_RUNBOOK.md`: Google Flow / Gemini Omni production workflow
- `flow-upload-pack/`: Flow-friendly image references and paste prompts when `.html` upload is not supported
- `handoff.html`: visual handoff page
- `prototypes/`: local, controllable intro animation prototypes
- `assets/style-board.png`: style board
- `assets/wordmark-night.png`: title/wordmark reference

## Production Notes

- No on-screen text in generated video shots.
- Leave negative space for the final wordmark/title treatment.
- Avoid glossy sci-fi, neon cyberpunk, cartoon, anime, and modern stock-video polish.
- Keep the mood reverent, slow, and human.
